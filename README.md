# vba-portfolio
# VBA開発ポートフォリオ

Excel VBAを活用した業務効率化・自動化ツールの開発実績をまとめています。
ただ動くマクロではなく、**「保守性の高さ」「処理速度の高速化」「エラーハンドリング」**を意識した実務向けのコード記述を心掛けています。

---

## 🛠️ 開発したツール・マクロの概要

### 1. 【ツール名：フォルダ作成マクロ】
【任意の名称のフォルダを作成、重複していたら末尾に(1)を付けて作成】

*   **解決した課題（導入効果）:** 
    *   あらかじめ名前が決まっているフォルダはボタン一つで作成
*   **主な機能:**
    *   フォルダを予め指定した名称で新規作成
    *   重複したフォルダがあれば、末尾に(1)を加えて強制作成
---

## 💻 技術的なこだわり（VBA実装のポイント）

実務で安定して運用できるよう、以下のベストプラクティスを取り入れて実装しています。

*   **関数分け:** 
    コアな処理は関数にしてコードを分けました。コードの変更が容易になり、仕様変更をすぐ行うことができます。
---

## 📂 公開ファイル構成

*   `【ファイル名】.bas`: 標準モジュール（メインの処理ロジック）
*   `【ファイル名】.cls`: クラスモジュール（【使用している場合のみ記載。データ構造の定義など】）
