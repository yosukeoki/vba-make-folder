# vba-portfolio
# VBA開発ポートフォリオ

Excel VBAを活用した業務効率化・自動化ツールの開発実績をまとめています。
ただ動くマクロではなく、**「保守性の高さ」「処理速度の高速化」「エラーハンドリング」**を意識した実務向けのコード記述を心掛けています。

---

## 🛠️ 開発したツール・マクロの概要

### 1. 【ツール名：フォルダ作成マクロ】
【任意の名称のフォルダを作成、重複していたら末尾に(1)を付けて作成】

*   **解決した課題（導入効果）:** 
    *   あらかじめ名前が決まっているフォルダはボタン一つで作成
*   **主な機能:**
    *   データの重複や入力漏れを自動で判定する「バリデーションチェック機能」
    *   送信可否や進捗が一目でわかる「ステータス管理シートへの自動反映」
    *   万が一の動作停止を防ぐ「エラーログの外部テキスト出力機能」

---

## 💻 技術的なこだわり（VBA実装のポイント）

実務で安定して運用できるよう、以下のベストプラクティスを取り入れて実装しています。

*   **高速化の徹底:** 
    `Application.ScreenUpdating = False` や `Application.Calculation = xlCalculationManual` を徹底し、画面更新の抑止と自動計算の制御による処理速度の最適化を行っています。
*   **マジックナンバーの排除:**
    列番号や固定値はすべて上部で定数（`Const`）として定義し、仕様変更（列の追加など）があっても1箇所の修正で済むよう「保守性」を高めています。
*   **堅牢なエラーハンドリング:**
    `On Error GoTo` を配置し、予期せぬエラー発生時にもユーザーに分かりやすいメッセージを表示した上で、変更したExcel環境の設定を安全に元に戻して終了する構造にしています。
*   **オブジェクトの明示:**
    `Range` などのオブジェクト指定において、シート（`ws`）の指定を絶対に省略せず、意図しないシートへの誤書き込みを防止しています。

## 📂 公開ファイル構成

*   `【ファイル名】.bas`: 標準モジュール（メインの処理ロジック）
*   `【ファイル名】.cls`: クラスモジュール（【使用している場合のみ記載。データ構造の定義など】）
